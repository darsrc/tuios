# Tape Recording

The recording guide lives on the docs site: https://dartuios.dev/docs/tape-recording

Recording is in-app: `Ctrl+B T r` starts, `Ctrl+B T s` stops. Tapes land in the directory `dartuios tape dir` prints, `$XDG_DATA_HOME/dartuios` (`~/.local/share/dartuios` on Linux), and are managed with `dartuios tape list`, `show`, `play`, `delete`. There is no `tape record` or `tape run` subcommand.
