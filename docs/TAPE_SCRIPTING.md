# Tape Scripting

The tape DSL reference lives on the docs site: https://dartuios.dev/docs/tape-scripting

It documents every keyword the parser accepts, timing, `dartuios tape play`, `validate`, and `exec`, and what parses but does nothing. Recording happens in-app on `Ctrl+B T r`; see also [PROJECT_TAPES.md](PROJECT_TAPES.md) for `.dartuios.tape` autorun and its trust boundary.
